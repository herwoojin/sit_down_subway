🔑 내 실시간 API 키

서울시 실시간 지하철 인증키(본인 발급)를 붙여넣고 저장하면, 내 키의 하루 1,000건 한도로 동작해요. 로그인하면 계정에 저장돼 계속 사용돼요.

서울 실시간 지하철 인증키 발급 — 단계별
  1. 서울 열린데이터광장 접속 → data.seoul.go.kr
  2. 우측 상단 회원가입 후 로그인 (무료)
  3. 상단 검색창에 "지하철 실시간 위치정보" 검색
  4. 「서울교통공사_지하철 실시간 위치정보」(Open API) 선택
  5. 페이지의 [인증키 신청] 클릭 → 활용목적 간단히 입력 → 신청
    (실시간 지하철은 보통 즉시~1·2일 내 자동 승인)
  6. 로그인 상태에서 마이페이지 → 인증키 관리(또는 일반 인증키)로 이동
  7. 발급된 인증키 문자열을 복사 (영문+숫자 약 30자)
  8. 이 화면 입력칸에 붙여넣고 「저장하고 사용」 클릭 ✅

※ 같은 인증키로 실시간 도착정보도 함께 동작합니다.
※ 한도 초과 시 매일 자정(00시, KST)에 자동 리셋됩니다.
